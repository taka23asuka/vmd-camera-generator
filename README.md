# VMD Camera Generator

音楽のビート（波形エネルギー）を解析し、MikuMikuDance（MMD）用のカメラモーション（`.vmd`）をブラウザ上で自動生成するWebアプリケーションです。  
主に **ショート動画（縦画面 9:16）やダンスMV** に最適化されたダイナミックなカメラワークを出力します。

🔗 **Web App:** [https://vmd-camera-generator.vercel.app](https://vmd-camera-generator.vercel.app)

---

## 🌟 主な機能

### 1. スタジオ風 1画面完結ワークスペース (Studio UI)
- **上部固定ヘッダー:** タイトル・バージョン情報・リセット機能を常時表示。
- **大画面3Dプレビューモニター:** Three.js によるサイバー棒人間リアルタイムプレビューを左側に常時展開。画面内のオーバーレイボタンで「生成カメラ視点」と「全体視点（ディレクターズカメラ）」をワンタッチ切り替え可能。
- **下部固定タイムラインドック:** メディアプレイヤー（再生/一時停止、シーク、1Fコマ送り、時間表示）と時間軸バー、カット編集カードトレイが画面最下部に常時ドッキング。

### 2. 楽曲連動の自動カメラ演出（全10パターン）
音声の音量エネルギー（サビ・盛り上がり vs 静けさ）およびテンポ感を解析し、最適なカメラワークを動的抽選（Weighted Random）します。
- **引き（wide）：** 縦画面いっぱいに全身のダンスと足元エフェクトを収めるフルショット
- **寄り（closeup）：** 表情に完全ロックオンするアイキャッチ（第1カットに確定配置）
- **斜め俯瞰（highangle）：** 上空から見下ろすドラマチックな立体感ショット
- **ローアングル（lowangle）：** 床スレスレから靴先〜頭まで捉えるダイナミック煽り
- **オービット（orbit）：** 正面を挟んで斜め前を回り込むバストアップ旋回
- **ドリー（dolly）：** センターを維持しながら引きから顔元へ真っ直ぐ迫る・引く
- **ダッチアングル（dutch_angle）：** 画面を斜めに傾けながら迫る疾走感エモショット
- **ティルトアップ（tilt_up）：** 脚部・ステップから顔の表情へ駆け上がる見上げショット
- **スナップドリー（snap_dolly）：** 最初の0.25秒で顔面へ急接近するアタックショット
- **スライド（slide）：** 画面外からスライドインし、中央でキメて通り抜けるトラッキングショット

- **カメラの激しさ（振幅）調整:** 30%（控えめ・バラード向き）〜 200%（激しい・EDM向き）までカメラのダイナミック度をスライダーで自由に変更可能。

### 3. タイムライン手動編集 ＆ ワンクリックジャンプ（Undo/Redo対応）
- **ワンクリックジャンプ:** タイムラインのバーやカットカードをクリックすると、プレビューが一瞬でそのカットの開始フレームへシークジャンプ。
- **カット手動分割（✂）:** 再生位置（現在のフレーム）でカットを2つに分割し、新しいアングルを挿入可能。
- **カット結合・削除（🗑）:** 不要なカットを削除して、前のカットとシームレスに合体。
- **パターン個別手動変更 & 固定（🔒）:** カードのドロップダウンでカメラワークを直接変更。お気に入りのカットを「固定中」にすることで、再生成時もアングルを維持。
- **アンドゥ / リドゥ (Undo/Redo):** 編集操作を `Ctrl + Z`（戻す）や `Ctrl + Y`（やり直す）でいつでも安全にやり直し可能。

### 4. モーション配布・確認用「正面固定モード」
- 音声ビートによるカット割りを行わず、正面固定でキャラクターを全身中央に捉え続けるモード。
- 「センター」だけでなく「全ての親」「グルーブ」の移動量も合成して左右に滑らかに追従します（高さは固定）。

### 5. トランジション（画面切り替え効果）
- ウィップ・パン（横スワイプ）やスピン（180度回転）をサポート（初期設定はOFF、UIでON/OFF切り替え可能）。

### 6. MMDモデル（PMX / PMD）連携による目線高さの自動検出
- キャラクターモデル（`.pmx` または `.pmd`）をドロップするだけで、モデル固有の上の「両目」「頭」ボーンの初期座標から目線の高さを自動抽出して適用（任意入力）。
- 3Dプレビューの棒人間もモデルの身長に合わせてリアルタイムに自動伸縮するため、どんな等身のモデルでもプレビューとカメラの構図が完璧に一致します。

## 🛠 技術スタック・アーキテクチャ

- **フロントエンド:** React 18, TypeScript
- **ビルドツール:** Vite
- **3Dグラフィックス:** Three.js
- **スタイリング:** Tailwind CSS
- **デザインパターン:** Strategy パターン（各カメラワークを `src/lib/strategies/` に1ファイルずつ完全カプセル化）
- **音声解析:** Web Audio API (RMS Energy Analysis / Adaptive Peak Detection)
- **バイナリ処理:** DataView (VMD Binary Parser & Serializer)
- **ホスティング / CI/CD:** Vercel
